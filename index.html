About个人简介

Biography学术履历

I received my B.S. degree in Software Engineering from HUST in 2016 and my Ph.D. degree in Computer Science and Technology from HUST in 2022, advised by Prof. Song Wu. From 2018 to 2019, I visited the University of Texas at Arlington for joint doctoral training with Prof. Jia Rao. My work has appeared in systems venues including SOSP, OSDI, SC, EuroSys, IEEE TC, HPDC, Middleware, ISMM, and APSCC. I am interested in building mechanisms that connect clean system abstractions with production constraints in large-scale cloud platforms.

我于 2016 年在华中科技大学获软件工程学士学位，2022 年在华中科技大学获计算机科学与技术博士学位，导师为吴松教授；2018-2019 年赴德克萨斯大学阿灵顿分校联合培养，合作导师为饶嘉教授。相关研究成果发表于 SOSP、OSDI、SC、EuroSys、IEEE TC、HPDC、Middleware、ISMM、APSCC 等系统领域会议与期刊。我关注如何在大规模云平台的真实约束下设计清晰、有效的系统机制。

Research研究方向

Interests研究兴趣

Operating systems and virtualization操作系统与虚拟化

Kernel mechanisms, memory virtualization, nested virtualization, and secure execution environments.内核机制、内存虚拟化、嵌套虚拟化与安全执行环境。

Containers and cloud-native infrastructure容器与云原生基础设施

Secure containers, resource views, scheduling, and production-oriented cloud runtime systems.安全容器、资源视图、调度机制以及面向生产环境的云运行时系统。

Elastic and serverless systems弹性与 Serverless 系统

Resource management for variable CPU and memory availability, distributed shared memory, and stateful services.面向 CPU/内存弹性、分布式共享内存与有状态服务的资源管理。

Cloud systems for AI面向 AI 的云计算系统

System support for LLM inference, agent workloads, sandboxing, and AI-oriented cloud platforms.面向大模型推理、智能体负载、沙箱隔离与 AI 云平台的系统支持。
